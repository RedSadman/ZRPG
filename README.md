# Сон Жовтого Проса / Yellow Millet Dream

Zero-player xianxia RPG у браузері: поки вариться просо, герой уві сні проживає ціле життя, а після пробудження виносить у реальність одну нагороду. ZRPG (Zero Role Player game) — кодова назва репозиторію, задум ще з 2016 року.

## Команди

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest
npm run typecheck
npm run build      # статична збірка в dist/
```

## Структура

| Тека | Що там |
| --- | --- |
| `src/engine/` | Ядро симуляції: чисті детерміновані функції, без DOM, `Math.random()` і `Date.now()` |
| `src/clock/` | Реальний час: тіки, офлайн-прогрес |
| `src/save/` | Збереження в localStorage, версії схеми й міграції |
| `src/i18n/` | Тексти українською та англійською |
| `src/narrator/` | Перетворює події ядра на рядки журналу |
| `src/ui/` | Інтерфейс на Preact |

Події в журналі зберігаються як дані, а не як текст, тому мову можна перемкнути будь-коли.
